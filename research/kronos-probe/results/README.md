# kronos-probe/results — the probe's JSON outputs

What the probe wrote, read with `../README.md` (the design, and its status:
instrument built and priced, no result yet). The folder matches an ignore
rule; these five files are tracked on purpose, and so is this index.

| file | what it is |
|---|---|
| `bar_validity.json` | the bar-validity check |
| `controls.json` | the control runs |
| `pricing.json` | what a full run would cost |
| `probe_pattern_summary.json`, `probe_random_summary.json` | the summaries for the pattern-selected and the random populations |
