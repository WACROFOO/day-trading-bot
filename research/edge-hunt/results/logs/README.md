# results/logs/ — raw console output behind REPORT.md

| File | What |
|---|---|
| `v3_F1.txt` … `v3_F5.txt` | the final search run (v3) of each family, train and validation |
| `sensitivity.txt` | F2's holdout under the three cost models, and the other families' chosen configurations (train/validation) |
| `f2_v3_sensitivity.txt` | F2's holdout re-read without the reverse-split days (same configuration, nothing re-chosen) |
| `final_v3_numbers.txt` | the bot today (B0) by window, cost model and stop width; F2 split by the scanner condition at the arm |
| `explore_pit.txt` | the first (v2) exploratory split of F2 by the scanner condition, and its audit sessions; exploratory, train/validation only |
