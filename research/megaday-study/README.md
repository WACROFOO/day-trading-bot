# megaday-study/

**Etude terminee.** 250+ megadays a la minute : anatomie, taux de base,
surfaces stop/sortie, protocole gele et holdout ouvert une fois.

| File | What |
|---|---|
| `RESULTS.md` | **le verdict** — moteur de rejet, pas de generation de signal |
| `PLAN.md` | le plan effectivement suivi |
| `data/` | les artefacts de l'etude |

Resultat durable : l'echec des backtests etait un echec de **parametre**, pas
de strategie — le cap de stop a 3% n'a jamais ete source et tombe sur la
mediane de la population.
