# Trading was HARD Until I Learned this BASE HIT Strategy

## Summary

After analyzing ten months of 2017 trading data, the speaker discovered that most profit came from frequent small winners (base hits, $0-$4,000 trades) rather than occasional home runs. This insight led to reducing position size from 15,000 to 6,000-10,000 shares, which paradoxically increased monthly profit by allowing better risk management and less slippage.

## Mechanical rules

- [00:10:12] Focus exclusively on "base hit" trades ($0-$4,000 wins); abandon home-run mentality.
- [00:12:31] Reduce position size from 15,000 to 6,000-10,000 shares.
- [00:26:55] Start each day with maximum 5,000-share position size until profit target ($1,000+) reached.
- [00:26:46] After $1,000 daily profit, increase position size cap to 10,000-15,000 shares.
- [00:27:58] Set maximum daily loss equal to daily profit goal (e.g., $5,000 loss cap with $5,000 profit goal).
- [00:13:06] Limit losing trades to under $2,000 each.
- [00:13:05] Target winning trades between $0 and $4,000.
- [00:14:43] Smaller position size makes it emotionally easier to cut losses.

## Setups and patterns

- **Double top** — two peaks at same level creating resistance.
- **Cup and handle** — base formation then handle pullback, breakout pattern.
- **Double bottom** — two lows at same level creating support.
- **Topping tail/shooting star** — reversal candle with long upper wick.
- **Dogee candle** — opening and closing at same level showing indecision.
