# How I use Thinkorswim Platform for Day Trading (Settings, Charts, Hot keys)

## Summary

TD Ameritrade's thinkorswim platform setup for active day trading: multi-monitor layout with charts on separate display, active trader window for order management, and customized hotkeys for fast order entry and exits. Balance between free commissions and slower execution speed vs. boutique high-speed platforms.

## Mechanical rules

- [00:03:08] Set order submission rate limit to 0 (in settings) to allow unlimited rapid order placement.
- [00:25:31] Set system quote speed to "real time" in application settings for faster data refresh.
- [00:06:09] Use "buy ask" order type for volatile stocks to avoid slippage vs. market orders.
- [00:16:26] Customize active trader window: remove unused columns (expiration, volume) to reduce clutter.
- [00:14:00] Link multiple charts together using order linking so switching one chart updates all linked charts.
- [00:11:46] Use sell half hotkey (Ctrl+X) instead of sell full position to force discipline in profit-taking.
- [00:04:49] Use moving average 200 (exponential) on daily chart at 2:00 line width, magenta color for visibility.

## Setups and patterns

- **Two-monitor setup** — One monitor for order entry/active trader, second monitor for charts. [00:04:31]
- **One-minute and five-minute chart pairing** — Primary 1-min chart for precise entries, 5-min for trend context. [00:13:02]
- **Daily chart with 200 EMA** — Used to check daily resistance levels (e.g., stock hitting 200 EMA resistance). [00:10:46]

## Indicators, tools, platforms
