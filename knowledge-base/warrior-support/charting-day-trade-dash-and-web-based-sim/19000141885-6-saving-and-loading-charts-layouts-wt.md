## About Chart Layouts

Chart layouts are helpful for loading a custom layout or adding a new chart without having to manually apply each setting you've used before. 

Chart layouts will save the following for each chart widget: 

- All [chart settings](https://support.warriortrading.com/support/solutions/articles/19000143137-2-3-chart-settings)
- All[ chart indicators](https://support.warriortrading.com/support/solutions/articles/19000141884-4-chart-indicators) 
- All [chart drawings](https://support.warriortrading.com/support/solutions/articles/19000141887-3-chart-drawing-tools-and-their-functions)
- The current stock ticker
- The current chart time frame

Chart layouts do not save:

- Multiple charts or multiple windows
- Other chatroom widgets
- [Color link function](https://support.warriortrading.com/support/solutions/articles/19000141886-2-1-linking-windows-navigating-the-top-toolbar-on-charts#12.-Change-Color-Group-(How-to-Link-Windows))

Read on below to learn specifics of chart layouts, or start with the video as a guide of overall layout functions.

## How to Save Chart Layouts

- From the top toolbar of the chart, click the blue Save icon (you may need to scroll to the right on your chart until you see the Save icon). If you have the chart widget selected, you can also save the chart layout by pressing Ctrl+S.

[image]

- A new widget will pop up for you to name the layout.

In case you missed the guide or the directions at the top of this article. You can easily save over chart layouts automatically per our [DTD layouts guide here.](https://support.warriortrading.com/support/solutions/articles/19000126510-how-to-adjust-save-load-day-trade-dash-and-chat-room-layouts-wt/preview#How-to-Save-all-Windows-(to-appear-on-your-next-login))

IMPORTANT: You cannot save any layout name starting with WT, and you cannot save over the default WT layouts. Any changes made to them will not save.

If you would like to make a change to a default WT layout, use the Make a copy function first and then save your copy of the layout under a different name.
 
[](https://support.warriortrading.com/support/solutions/articles/19000126510-how-to-adjust-save-load-day-trade-dash-and-chat-room-layouts-wt/preview#How-to-Save-all-Windows-(to-appear-on-your-next-login))

## How to Rename and Copy Chart Layouts

- To the right of your current layout, you will see a small up/down arrow. Please click on this to bring up the layout menu:
Rename: If you already have a current layout selected, you can use this function to rename the layout.
- Make a copy: If you already have a chart layout selected, you can use this function to duplicate a copy of the layout with an option to rename it.

## Error: Chart layout names with "WT" did not save

If you get the error message, you should see an option on the right side to X-out of the alert or "click here" to get redirected to our guide here on how to copy or rename a layout that is not a protected default layout. 

You have the option to ignore this if you mistakenly made a change to the default layout and do not care that your settings are not going to be saved.

If your intention is to actually save this layout, you will then need to save it as a new layout without the WT in front of the name.

As the guide states in the directions #How-to-Rename-and-Copy-Chart-Layouts[earlier in this support article](#How-to-Rename-and-Copy-Chart-Layouts), please click on the arrow to the right of layout and select the "Make a copy" function.

Then, rename the layout you copied to your preference, without "WT" in the title.
