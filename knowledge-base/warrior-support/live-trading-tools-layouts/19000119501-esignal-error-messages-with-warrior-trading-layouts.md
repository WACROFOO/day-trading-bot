# eSignal Error Messages with Warrior Trading Layouts

Warrior Pro members have access to demos and layouts for various trading tools used by traders in our community. [Warrior Pro members can find eSignal layouts here](https://www.warriortrading.com/layout-installation-for-esignal/) when they are signed into their Warrior Trading account. This article is designed to help resolve error messages that have been reported by the community when using these layouts.

Click Error Message Below to Learn More

- ["TASIndicators/TAS Boxes.efs: Error loading script"](#)

This support article will be updated as we learn more about various errors that members may encounter when using our eSignal layouts. If you'd like to help improve this article, members using our layouts are welcome to forward us information about error messages and tips that helped!

### "TASIndicators/TAS Boxes.efs: Error loading script"

[image]

This is a common error message when using Ross' eSignal layout if you are not subscribed to the TAS add-on. TAS is an indicator developed by a team lead by our old futures trader Steve. You can check out more on the indicator here if you'd like! [](https://www.wetradedesk.com/)[https://www.marketprofileindicators.com/](https://www.marketprofileindicators.com/)

To remove the error:

- 
Right click on the chart
- 
Click Edit Chart
- 
Uncheck TAS Boxes.efs.

[image: image.png]

The indicator may be enabled on the 10-second, 1-minute, 5-minute, and/or daily charts. Complete this process with all charts unless you plan to purchase the TAS add-on. [Click here to learn more about eSignal add-ons](https://www.esignal.com/add-ons).
