# warrior-support — the help-desk corpus

126 articles fetched from the public [support portal](https://support.warriortrading.com/support/solutions), in the portal's own two-level tree.

A **third written register**, distinct from `warrior-blog/`: the blog
explains a strategy, these pages say which button produces it — scanner
columns, order routing, halt codes, extended-hours rejects, platform
mechanics. Operational, not directional. Nothing here is an edge claim.

Rebuild: `python scripts/fetch_warrior_support.py` (cached; re-runs are cheap)
