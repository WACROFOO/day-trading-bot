# Interactive Brokers

Interactive Brokers (IB) Substantiation Example - Realized Summary Report Report:

There are two sections of this report we'll need to review in order to verify profits from IB. We need to see your net short term profit totals and time period for the report. We also need to see the name on the report so that we can confirm you're the owner of the broker account. 

Please do not send two separate images from this report. We will need to have the full report submitted, which you can compress if the file is too large. You can feel free to blur/redact the information in the body of the report, as we'll only need to review the beginning and end of the file.

The full name on file with the broker account should be visible on the first page. Please also keep the 'Account Type' section visible. See image below for example:

[image]

To verify your profits, we'll need to see the total realized short-term profit totals from this same report.
