# Switch to Dark Mode or Light Mode in Chat Room | WT

Dark mode is a display setting that changes the background color to a darker color and text to contrasting colors. Some members prefer this since it tends to be "easier on the eyes," though many others prefer light mode. You can learn how to switch between these two modes in our chat room below:

1. After [signing into the chat room](https://support.warriortrading.com/en/support/solutions/articles/19000024073), click Profile in the bottom corner of the left-hand menu.

[image]

3. Go to Appearance and switch the radio button between dark or light mode.

[image]

4. Click Save to apply your changes.
