How to Save and Load a Single-Window and Multi-Window Platform Layouts

## Terminology for Platform Layouts

Widget: A widget is an individual box within the Warrior Trading platform for rooms or tools which can be selected from the left sidebar. The image below identifies a chat room widget (yellow outline), a charting widget (blue outline), and a stock quote widget (white outline):

[image]

Window: This term refers to your browser window that displays our platform and may hold multiple widgets within it. The image above is one window.

Main window: This is the first window that appears when you enter the platform, and from which you may pop out other windows.

- If your profile picture is visible on the bottom left of the window, this will indicate it is the main window.
- The pop-out function only works from this main window.

Pop-out window: This refers to any browser windows created from your main window by either using the pop-out feature on the top right of the window or the pop-out feature from the layout settings. 

- Currently, you are only allowed a maximum of 5 extra pop-out windows.
- You cannot pop out a new window from a pop-out window.

Layout: a specific arrangement of widgets within one window.

- You are currently allowed an unlimited number of chart widgets per window.
- Only one of each widget is allowed per window for the chatrooms, watchlist, or individual scanner.  
- These are divided into three categories, shown below.

## Types of Layouts

- Warrior Trading Window Layouts: These are publicly available layouts of one window layout, curated by our team. 
You cannot edit this layout, but you can save new personal layouts based on it.
- The green "D" in this section (as shown below) identifies which layout is set as the default layout for new users.

- Personal Window Layouts: layouts of one browser window that you created and saved
There is currently a limit of 5 personal window layouts. If you reach this limit, you will see: Windows Limit Reached

- Platform: The part of the Warrior Trading website for Day Trade Dash and chat room.
The platform should save upon logging out. You can ensure the saving of your whole platform through one of the methods below.

## How to Save Individual Window Layouts

It is useful to have individual browser windows saved to be cloned later or to load individually in the future. To save the layout of widgets populating the browser window you are currently using, follow these steps:

- Make your preferred layout in one window.
- In the same window, go to Layouts > Save Current Window.
- Enter a name that will help you identify the layout.
- Click Save.
- Repeat the process for any other windows if you have a multi-window layout or if you have plans to clone this one window in the future.

[image]

## How to Save all Platform Windows as Default (to appear on your next login)

This is the feature for saving layouts that most members will want to use to ensure all their layouts and widgets save at once.

Simply go to the Layouts section of Settings on the left-hand menu, and click Save all Windows.

[image]

If you are logging out for the day, you can save and logout by clicking your profile picture in your main window, followed by Save & Logout.
[image]

If you are already viewing your layouts, we also give you the chance to save all your windows there:

- In your main window, click Layouts > Save all windows as Default.
- A gray indicator will appear, showing the save was successful and a timestamp. You can click Close to exit.
[image]

### Error: Changes to Default Charts Not Saved

This error may appear in one of two ways, depending if you are trying to save your layout from the Settings or using the Save & Logout function:

[image]

[image]

This error means that while most of your platform layout has been saved, changes to the default chart templates have not been saved. Default charts are any charts currently on your layout that have "WT" in the chart layout name.

If you want to keep your layout saved with the default "WT" charts, no further action is needed.

However, if your intention is to save an edited version of these charts, please follow [this link to our charting support article](https://support.warriortrading.com/support/solutions/articles/19000141885-6-saving-and-loading-charts-layouts-wt#How-to-Rename-and-Copy-Chart-Layouts) to learn how to rename your chart layouts. Then, save your platform layout again.

## How to Load, Pop Out, or Delete a Layout

For all your personal layouts, you can choose from the following:

[image]

- Load the layout: This will load the layout in the same window you are using and replace what you currently have.
- Pop up the layout: This will load the layout in a new window.
- Delete the layout: This will delete this saved layout.

## Troubleshooting Pop-Out Windows

If you are having trouble getting external / popped-out windows to appear when loading a layout, please check if your browser is blocking pop-ups. If you are not familiar with your browser's pop-up settings, [this article may help](https://support.warriortrading.com/support/solutions/articles/19000130049).
