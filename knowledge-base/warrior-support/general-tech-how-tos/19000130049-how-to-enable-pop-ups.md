# How to Enable Pop-Ups

Select Your Browser:

- [Chrome Web Browser](#Chrome-Web-Browser)
- [Safari Mobile Browser (iOS)](#Safari-Mobile-Browser-(iOS))

### Chrome Web Browser

Make sure your pop-up settings are enabled under Privacy and security settings: chrome://settings/content/popups 
[image]

### Safari Mobile Browser (iOS)

The instructions below review how to enable pop-ups on Safari browser on iPhone/iPad.

- Go to your iOS settings and click on Safari or other settings for other browser you are using.

[image]

- Toggle off the setting to "Block Pop-ups"

[image]
