# Using the Stock Quote Widget and Cashtags for News | WT

### Adding a Stock Quote Widget

For members with scanner access on their platform, one stock quote widget can be added per platform window. To have more than one, you must pop out a new platform window.

To add the stock quote widget, go to your Tools section on the left side menu and click Stock Quote.

[image]

Within the Stock Quote Widget, you can view current and live information for the stock as described throughout the remainder of this article.

### Common Error Message - Please open and color link a Stock Quote widget

Clicking a ticker from our scanners will open information about that stock in your stock quote widget. If you don't already have your Stock Quote widget open on your platform, open it first by selecting Stock Quote from the left-hand tools menu:

[image]

You'll then want to link your Stock Quote widget to your scanner by selecting the same color via the color link function. To do this, simply click the link symbol that appears in the upper right-hand corner of your Stock Quote widget and select a color. Then, do the same on your scanner window, selecting the same color so that the windows are linked in the same color group.

[image]

Then link your Quote widget with the same color: 

[image]

To learn more about how to use the color link function in the chatroom and charts, please [see our guide here.](https://support.warriortrading.com/support/solutions/articles/19000141886-2-1-linking-windows-navigating-the-top-toolbar-on-charts-wt#12.-Change-Color-Group-(How-to-Link-Windows))

### Functions of the Quote Widget

Typing a stock ticker in the search bar and pressing Enter will pull up the stock and its data within the stock quote widget. The letters do not need to be capitalized when searching.

If using the [color link function](https://support.warriortrading.com/support/solutions/articles/19000141886-2-1-linking-windows-navigating-the-top-toolbar-on-charts-wt#12.-Change-Color-Group-(How-to-Link-Windows)), you can click on tickers or enter stock tickers on other linked widgets to make them appear on the stock quote widget. Similarly, the color link function allows you to type tickers on the stock quote widget and simultaneously have them appear in the other linked widgets.

 We recommend using this feature to increase the speed at which you can navigate our platform.

The Stock Quote widget displays a stock's current news headlines, price, fundamental attributes, and technical data. Traders can use this information to interpret how a particular stock fits within the market at its current price.

#### Using Recent News Headlines

The top three recent news Headlines appear here. If you would like to see up to 20 of the most recent headlines, you can click the button on the right that says More. Once expanded, you can click the Less button to minimize again.

This news section has a few pieces of information you will want to be aware of:

- Freshness:  This indicator shows how "fresh" or new a headline is. You can hover over the icons to see what they represent, as also demonstrated in the chart below.

### Pop-Up Alerts

To adjust how the quote widget and news headlines interact in the platform, go to the bottom of the left side tool menu and click Profile under the Settings section. You should see a section called Notification and Window Settings.

Read on to learn about each of these settings. A pink checkmark means the setting is enabled, while a gray X means the setting is disabled.

[image]

- Pop Up News Detail in a New Browser Window
If on, it will pop out news articles from the quote widget to a new browser window.
- If off, it will open up your news article in a new tab on the same browser window.
- By default, this setting is set to on.
- Cashtags go to Quote Website
When turned on, this makes it so that clicking on a cashtag will direct you to our [quote page](https://www.warriortrading.com/quote/). 
- By default, this is turned off. 
- If turned on, it also disables function #3, and clicking on a ticker no longer forces you to be linked to the quote widget.
- If you do have a linked quote widget, they will still work.
- Quote Widget Reminder for $Cashtags
This setting will display a pop-up message when you click on a cashtag without a linked quote widget. This is on by default.
- If you do have a quote widget open, you will be reminded to link it [with the color link function.](https://support.warriortrading.com/support/solutions/articles/19000141886-2-1-linking-windows-navigating-the-top-toolbar-on-charts#12.-Change-Color-Group-(How-to-Link-Windows))

### About Cashtag Functions

We encourage chat members to use the cashtag when talking about stocks. This can be done by entering the symbol $ before the ticker. Once you enter your message into the chat, our chat room will make the cashtag clickable so that members can easily look up the ticker (similar to clicking on the ticker within the stock quote widget).

For example: If wanting to share about AAPL, you can type: "Watching $aapl"
