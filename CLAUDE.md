# Project instructions

- **Reply format:** follow the `concise-update` skill
  (`.claude/skills/concise-update/SKILL.md`) for every reply. Keep replies
  short: key findings, analysis, open points, next steps. Details go in the
  repo docs.
- **Public repo:** never commit personal amounts, account details, trade logs
  or API keys. `systematic/private/` and `.env` are gitignored for that.
- **Active work** lives in `systematic/`; the crypto track is the current
  focus (`systematic/crypto/PLAN.md`).
